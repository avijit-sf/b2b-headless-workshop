Before You Begin

Make sure you have the following ready before starting the workshop.

Salesforce Org

A Salesforce org with B2B Commerce enabled and Agentforce Vibes available. Your workshop org has been pre-configured.

Web Browser

Google Chrome or Microsoft Edge (latest version recommended). Safari and Firefox may have limited compatibility.

GitHub Repository

We'll clone the open-source storefront from:
github.com/trailheadapps/commerce-b2b-headless

Time Required

Approximately 30–45 minutes to complete all steps. The AI agent handles most of the heavy lifting!

Step 1

Access Agentforce Vibes

Launch the Agentforce Vibes IDE directly from your Salesforce org — no installation or setup required.

1
Access Agentforce Vibes

Agentforce Vibes is now native to your Salesforce org. You can launch it directly from the Setup Gear Menu.

1
Log into your Salesforce org. You'll land on the Lightning home page.
2
Click the Setup Gear icon (⚙️) in the top-right corner of the navigation bar.
3
From the dropdown menu, click Agentforce Vibes. This opens the IDE in a new tab.
The Setup Gear Menu showing the "Agentforce Vibes" option — click it to launch the IDE.
4
When prompted with "Do you trust the authors of the files in this folder?", click Yes, I trust the authors to enable all features.
Click "Yes, I trust the authors" to enable all IDE features.
💡
Tip: If you don't see "Agentforce Vibes" in the gear menu, navigate to Setup → Development → Agentforce Vibes IDE to verify it's enabled.

Move Chat to the Right-Side Panel

Step 3

Clone the Repository

Use the Agentforce Vibes chat to clone the B2B Commerce headless storefront repo from GitHub.

3
Clone the Repository

Now we'll use the Agentforce Vibes chat to clone the open-source B2B Commerce headless storefront repository.

1
Click into the Agentforce Vibes chat input field (at the bottom of the chat panel).
2
Type (or copy-paste) the following prompt:
Prompt
Clone https://github.com/trailheadapps/commerce-b2b-headless at /home/codebuilder/
3
Press Enter (or click the send button) to submit the prompt.
4
Wait for the agent to clone the repository. You'll see progress messages in the chat as the repo is downloaded.
💡
Tip: The cloning process typically takes 30–60 seconds depending on network speed. The agent will confirm when it's complete.

Switch the active workspace to the newly cloned commerce-b2b-headless project.

Change the Project Folder

After cloning, you need to switch the IDE workspace to the new commerce-b2b-headless project folder.

Step 5

Add the Deployment Skill

Install the pre-built deployment skill so the agent knows how to configure, build, and deploy the storefront.

5
Create the Skills Folder & Add the Skill

The Agentforce Vibes agent uses skills — pre-built instruction sets that teach the agent how to perform specific tasks. We need to add the deployment skill to our workspace.

Create the skills directory

1
In the file explorer, right-click in the root of the project and select New Folder.
2
Name it .afv (with the leading dot). Inside it, create another folder called skills.

Your folder structure should now include: .afv/skills/

Copy the deployment skill

3
Copy the commerce-b2b-headless-setup-deploy/ folder (provided by your workshop instructor) into the .afv/skills/ directory.
4
If the skill doesn't appear immediately, reload the window: press Ctrl+Shift+P (or Cmd+Shift+P on Mac), type "Reload Window", and select it.

Enable the skill

5
Open the Agentforce Vibes chat panel and click the Toolkit button (or gear icon).
6
Navigate to Skills and toggle ON the commerce-b2b-headless-setup-deploy skill.
❗
Do NOT use "+ Add Skill" for this one. That UI creates a single SKILL.md file and will miss the references/deploy-commands.md file that the skill needs. You must manually copy the entire folder as described above.

Step 6

Run the Deployment

Tell the agent to deploy the storefront — it handles configuration, building, and deployment automatically.

6
Run the Deployment Prompt

Now comes the exciting part — let the AI agent deploy the entire storefront for you!

1
Click into the Agentforce Vibes chat input field.
2
Type (or copy-paste) the following prompt:
Prompt
Use commerce-b2b-headless-setup-deploy skill to deploy B2B Commerce headless storefront
3
Press Enter to submit. The agent will begin the multi-step deployment process.

The agent will automatically:

  • Configure your org's WebStore ID, Buyer Group, and Permission Set Group
  • Install all Node.js dependencies
  • Build the React application with Vite
  • Deploy Apex classes, UIBundles, and Experience Cloud site metadata
  • Set up guest user permissions
  • Publish the site
💡
Tip: The full deployment typically takes 5–10 minutes. You can watch the agent's progress in real-time as it runs commands and reports status updates in the chat.

Step 7

Keep It Running

The agent may pause for confirmation at various stages — just click Run to continue.

7
Continue to Hit Run

During the deployment process, the agent may pause at certain stages and ask for your confirmation before proceeding. This is normal behavior.

1
When the agent pauses, you'll see a Run button appear in the chat. Click it to continue.
2
Repeat this for each pause — the agent may stop 3–5 times during the full deployment.
3
When the deployment is complete, the agent will confirm with a success message and provide the URL to your new storefront.
✔️
Success! Once the agent reports that deployment is complete, your headless React storefront is live! You can browse products, test the cart, and explore the full B2B commerce experience.
⚠️
If something fails: Don't worry! Read the error message in the chat, and ask the agent to try again or troubleshoot the issue. The agent can usually fix most problems on its own.
